What Gate 5 is (06_HUMAN_TASKS.md, 08_GATES_AND_CHECKLISTS.md): a qualitative read of generations 3 and 6 for each of the six confirmatory chains, 50 samples each (12 files), coded with the pre-specified rubric. It checks that the automatic measures match the text, and it feeds the paper's qualitative section. The gate passes when both of you have read and recorded the rubric, and any mismatch between the numbers and the text has been investigated.
  • Split by chain: each page is one chain, with generations 3 and 6 side by side (100 samples, about 2–3 hours). Split the six pages between you, for example three each.
  • Optional fluency rating: both of you rate the same 20 prompts per page (marked fluency subset) plus generation 0 on the two optional pages, 1–5, so that agreement can be reported. The author who coded a chain page rated its 20 prompts there; the other author rates the same prompts on that chain's own fluency page below (fluency only, without seeing the first ratings). Both authors rate the two generation-0 pages.
  • On each page, enter your name first, code the samples, then press Copy reply and paste the text into the Claude Code chat, one page at a time. The agent writes results/human_read/<chain>_gen<g>.csv with the sample file hashes, counts the codes per chain and generation, and places them next to the automatic measures. Disagreements between readers are reported, not resolved.
  • The pages show no automatic numbers and no highlighting, so that your coding is independent of the measures it checks.
  • Export progress on a page saves your answers to a JSON file; Import progress loads it back on the same page, so you can always continue where you left off (another browser or computer, a cleaned browser, or a regenerated page). Export after each session as a safety copy.
